# העוזר העסקי של רוית צור וייסלברג

פרויקט לניהול השיווק, המכירות והעיצוב של הפרקטיקה הטיפולית של רוית צור
וייסלברג — מטפלת זוגית ומשפחתית.

הקונטקסט העסקי והמותגי המלא נמצא בקובץ [`CLAUDE.md`](./CLAUDE.md).

## מבנה הפרויקט

```
assets/
├── logo/                 # קובץ לוגו
├── brand-images/         # תמונות מותג
├── bio/                  # טקסט "עליי" / ביוגרפיה קיים
├── pricing/              # מחירון או תיאור שירותים
├── website-content/      # תוכן קיים מהאתר, טיוטות קופי לדפים
├── course-materials/     # חוברות/סדנאות (ראה הערת זכויות יוצרים למטה)
├── content-frameworks/   # מסגרות עבודה לכתיבת תוכן (חומרי השראה חיצוניים, לא לפרסום כלשונם)
├── marketing-creatives/  # גרפיקות שיווקיות מוכנות
└── brand-strategy.md     # מסמך אסטרטגיית מיתוג ומיצוב

landing-pages/            # דפי נחיתה חיים (HTML מוכן לפרסום)
```

### הערה על תמונות הפורטרט
שתי תמונות הפורטרט (עם הפרח הבורדו) נשלחו הודבקו ישירות בצ'אט ולא כקובץ מצורף,
ולכן לא ניתן היה לשמור אותן אוטומטית בריפו. כדי שיישמרו ב-`assets/brand-images/`,
יש לשלוח אותן שוב כקובץ מצורף (attachment) ולא כתמונה מודבקת.

### הערה על חומרי `content-frameworks/`
הקבצים בתיקייה זו (הוקים לסטוריטלינג, חוברת "10 סוגי סיפורים", ה-Workbook
של VERA) הם חומרי לימוד/השראה **חיצוניים** — לא נכתבו על ידי רוית ולא ניתנים
לפרסום כלשונם. הם משמשים ככלי עזר פנימי לניסוח תוכן, לא כמקור לציטוט או
לתוכן מוכן.
